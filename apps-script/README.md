# Приём анкет в Google Таблицу

Делается один раз, из аккаунта alinasadykova2001@gmail.com (5 минут):

1. Создайте новую Google Таблицу (sheets.new), назовите «Анкеты — Посвящение».
2. Меню **Расширения → Apps Script**. Удалите содержимое и вставьте код из `Code.gs`. Сохраните.
3. **Развернуть → Новое развёртывание → тип «Веб-приложение»**:
   - «Выполнять как»: **я**
   - «У кого есть доступ»: **Все**
4. Нажмите «Развернуть», разрешите доступ (Google попросит подтвердить: «Дополнительно → Перейти…»).
5. Скопируйте **URL веб-приложения** (заканчивается на `/exec`) и пришлите его — он вставляется в `RSVP_ENDPOINT` в `script.js`.

Каждый ответ появится строкой в таблице (дата, ФИО, «Приду»/«Не приду») и придёт письмом на почту.
После любых правок кода в Apps Script нужно делать «Управление развёртываниями → изменить → новая версия».
